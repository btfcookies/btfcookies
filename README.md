## Colophon

Every sheet above is generated by [`scripts/build.mjs`](scripts/build.mjs) and refreshed daily by
[a scheduled workflow](.github/workflows/refresh.yml). Contribution counts come from GitHub's public
contributions fragment; everything else comes from the REST API.

The design has one constraint: no colour. A monochrome system has no hue to spend, so anything that
would normally be a colour becomes an area instead. The avatar is Atkinson-dithered to one bit, which
turns its rainbow into a field of dot densities. Contribution volume is dot area rather than a green
ramp. Language share is a fill pattern rather than a swatch. Each sheet is revealed by a print head
that steps down the page at a fixed rate, so the four images read as one pass of one machine.

Type is [Archivo Black](https://fonts.google.com/specimen/Archivo+Black) and
[IBM Plex](https://www.ibm.com/plex/), baked to outlines at build time — web fonts do not load inside
a proxied README image, and outlines keep the layout identical on every machine.
